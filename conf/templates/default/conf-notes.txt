### Shell environment set up for builds. ###

You can now run '[MACHINE=<machine>] bitbake <target>'

Microchip supported machines:
- PolarFire SoC Video Kit / mpfs-video-kit

Microchip targets:
    mchp-base-image

Microchip PolarFire SoC Video Kit supported machines/solutions:
    mpfs-video-kit-h264
    mpfs-video-kit-h264-mm
    mpfs-video-kit-raw-bayer
    mpfs-video-kit-tsn

Common targets:
    core-image-minimal
    core-image-minimal-dev
    core-image-minimal-mtdutils

Other commonly useful commands:
 - 'devtool' and 'recipetool' handle common recipe tasks
 - 'bitbake-layers' handles common layer tasks
 - 'oe-pkgdata-util' handles common target package tasks
